# Guides (in Portuguese)

Practical guides written during the project for the team that runs the platform. They are in Portuguese; the English
documentation is in [`documentation/`](../documentation/README.md).

| Guide | What it covers |
|---|---|
| `manual_do_utilizador.md` | User manual of the platform |
| `guia_de_deploy.md` | Publishing on GitHub and Streamlit Community Cloud, upkeep, troubleshooting |
| `alertas_whatsapp.md`, `modelos_whatsapp.md` | WhatsApp alerts: rules, Meta setup, the message templates |
| `guia_de_mensagens_de_alerta.md` | How alert messages are worded for each level |
| `teste_alerta_ponta_a_ponta.md` | End-to-end test of an alert message |
| `guia_servidor_proprio.md`, `guia_dominio_co_mz.md` | Own server and the `.co.mz` domain (prepared for later) |
| `estado_do_plano.md` | Status of every task of the project plan, with evidence |
| `semana_4_preparacao.md` | Preparation of week 4 (platform) and the decisions taken |
| `ficha_de_evidencia_do_problema.md` | Evidence sheet: the water-quality problem in numbers |
| `protocolo_de_campo_qualidade_da_agua.md` | A field protocol for turbidity and conductivity, kept for a possible later phase |
| `runbook.md` | The technical runbook of the project folder: every command, week by week (English) |
| `contas.sql`, `subscritores.sql` | Database tables for accounts and WhatsApp sign-ups (Supabase) |
