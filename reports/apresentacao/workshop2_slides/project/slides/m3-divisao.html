FACILITADOR 5, cerca de 1,5 minutos. "Na escola há duas fases: estudar e fazer o exame. No Machine Learning é igual. TREINO: o modelo estuda os exemplos com a resposta certa. Em Python, isto é uma linha: modelo.fit(X, y). X são as características (a tabela de números) e y são os rótulos (1 = água, 0 = não água). 'fit' quer dizer 'ajustar': o modelo ajusta-se aos exemplos. TESTE: damos ao modelo dados que ele nunca viu, sem lhe dizer a resposta. Ele PREVÊ: modelo.predict(...). Depois comparamos com a resposta certa e damos a nota. Se o professor desse no exame as mesmas perguntas do caderno de exercícios, a nota não diria se o aluno aprendeu ou se decorou." A barra mostra a divisão habitual: cerca de 70% dos dados para treinar e 30% para o teste, que fica "fechado à chave" até ao fim. Estas duas linhas de código aparecem na prática: os estudantes vão reconhecê-las.
