Mais complexo não é sempre melhor

Figura 18. Árvores de regressão em dados inventados (média de 200 amostras).

No treino, o erro desce sempre: o modelo decora cada vez mais.

No teste, desce até ao bom ajuste e depois sobe: é o sobreajuste.

Escolhe-se a complexidade com o erro no teste, nunca com o do treino.

FACILITADOR 5, cerca de 2,5 minutos. Um dos gráficos mais importantes de todo o Machine Learning. "No eixo horizontal, a complexidade do modelo: aqui, a profundidade de uma árvore (quantas perguntas seguidas). Duas curvas: - O erro no TREINO (preto) desce sempre: quanto mais complexo, mais o modelo decora os exemplos, até chegar a zero. - O erro no TESTE (vermelho) desce até um ponto, o BOM AJUSTE (aqui, 3 perguntas), e depois volta a subir: o modelo começou a decorar o ruído do treino. Conclusão: escolhe-se a complexidade com o erro no TESTE, nunca com o erro no treino. Se olhássemos só para o treino, escolhíamos sempre o modelo mais complexo, que é o pior." Na Aula 4 da prática, os pares fazem o mesmo com o caudal real do Incomáti (erro médio, em m³/s): a melhor profundidade é 5 (erro no teste 34,7); com 20 perguntas, o erro no treino cai para 0,1 e no teste sobe para 39,4.
