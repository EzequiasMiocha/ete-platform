FACILITADOR 2, cerca de 1 minuto. Vocabulário em Python que aparece na prática. "No computador, a tabela das pistas chama-se X e a coluna dos rótulos chama-se y. Treinar é uma linha: modelo.fit(X, y), quer dizer 'aprende com estes exemplos'. Prever é outra: modelo.predict(X_novo), quer dizer 'dá-me a resposta para estes casos novos'." É igual para todos os algoritmos do dia: a árvore, o Random Forest, os k vizinhos, a rede neuronal e a recta da regressão. No K-means (sem rótulos) só há fit(X), sem y: vamos ver porquê.
