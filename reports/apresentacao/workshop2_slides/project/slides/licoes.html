Conclusões: o que levamos para casa

1. As pistas certas

Sem a maré, o modelo não aprendia. Os dados contam mais do que o algoritmo.

2. A nota a sério é a do exame

Com dados que o modelo nunca viu. No tempo, o exame é o futuro.

3. Simples ou complexo?

Um modelo que decora o treino erra no teste.

4. As pessoas decidem

Um modelo honesto mostra onde erra. Os avisos oficiais vêm primeiro.
