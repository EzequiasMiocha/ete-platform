Inteligência Artificial

Computadores a fazer tarefas que pareciam precisar de inteligência humana: ver, ouvir, traduzir, decidir.

Machine Learning

Uma forma de fazer IA: o computador aprende com exemplos, em vez de seguir regras escritas por nós.

Deep Learning

Machine Learning com redes neuronais de muitas camadas. Precisa de milhões de exemplos. Está no tradutor e no ChatGPT.

EYES TO EARTH | Workshop de Estudantes 2 | Módulo 1: O que é a Inteligência Artificial?

12

FACILITADOR 1, cerca de 3 minutos. "Estas três palavras aparecem muito nas notícias. Uma está dentro da outra, como caixas. A caixa maior é a Inteligência Artificial: qualquer computador que faz uma tarefa que antes só uma pessoa sabia fazer. Dentro dela está o Machine Learning: a IA que aprende com exemplos. É o que vamos fazer hoje, com um método chamado Random Forest (floresta aleatória). Dentro do Machine Learning está o Deep Learning, a 'aprendizagem profunda'. Usa redes neuronais: muitas camadas de pequenas contas, inspiradas (de longe) nos neurónios do cérebro. É muito poderoso, mas precisa de muitíssimos exemplos: o reconhecimento facial aprendeu com milhões de caras e o ChatGPT com uma enorme quantidade de texto." Se perguntarem "o Random Forest é Deep Learning?": não. É Machine Learning clássico: funciona bem com poucos exemplos, é rápido e conseguimos ver como decide.
