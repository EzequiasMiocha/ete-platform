Como trabalhar no Jupyter Notebook

1. Abrir

Jupyter Notebook, pasta Workshop_2 › 2_pratica, e o notebook do tema.

2. Na aula guiada

Shift + Enter, sempre por ordem. Acompanhem o projector.

3. Na prática

Escrevam o código por baixo da pista (#) e corram a verificação: «Certo!» ou «Ainda não».

4. Erro vermelho?

Leiam a última linha. Se nada resultar: Kernel › Restart Kernel and Run All Cells.

Ctrl + S guarda o trabalho no computador.

FACILITADOR 5, 2 minutos, no projector (11:40). Mostrar no projector o Jupyter aberto na pasta 2_pratica e a Aula 1. Correr o Passo 1 com Shift + Enter e mostrar o [*] e depois o número. Depois abrir a Prática 1 e mostrar como se trabalha: em cada passo há uma PISTA (linhas com #). Escreve-se o código por baixo (pode-se copiar a pista, tirar o # e trocar os ...), corre-se, e depois corre-se a célula de verificação: diz «Certo!», ou «Ainda não» com uma pista. Guardar com Ctrl + S. Erros: ler sempre a última linha da mensagem vermelha. O mais comum é saltar uma célula: correr por ordem. Se o Python parar (Kernel died): menu Kernel, Restart Kernel and Run All Cells.
